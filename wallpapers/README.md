# Wallpapers for FapOS

Place your R34 wallpapers in this folder (or in `/usr/share/backgrounds/fapos/` after installation).

Recommended:
- High resolution (1920x1080 or higher)
- PNG or JPG
- Keep file sizes reasonable for the live ISO

The installer creates the system directory automatically.

**Note**: Actual adult images are not included in this repository for legal and size reasons. Add them yourself.
